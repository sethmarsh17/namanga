# Namanga Hope Center — Website

Static site for [Namanga Hope Center](https://www.facebook.com/NamangaHopeCenter), Namanga, Kenya.

- `index.html` — single-page site (no build step, no framework)
- `images/` — photos and assets

## Deploy

Hosted on Cloudflare Pages, connected to this repository. Every push to the
production branch deploys automatically; no build command, output directory `/`.
